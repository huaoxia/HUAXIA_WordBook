# 单词簿 - 运行说明书

---

## 系统要求

- Java 运行环境（JRE 1.8 或更高版本）
- Derby 数据库驱动（`derby.jar`）

## 默认账号

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 测试用户 | `user` | `user123` |
| 管理员 | `admin` | `admin123` |

---

## 运行方式

### 方式一：Eclipse 中运行（开发调试用）

1. 打开 Eclipse，导入项目
2. 右键 `ch3.gui.AppWindow.java` → **Run As → Java Application**（启动用户端）
3. 管理员端：右键 `ch3.admin.AdminWindow.java` → **Run As → Java Application**
   > 注意：管理员端需要传入管理员 ID 参数，或直接在代码中修改。

### 方式二：jar 包运行（发布用）

1. 确保 `EnglishBook.jar`、`AdminConsole.jar`、`derby.jar` 在同一目录
2. 双击 `englishBook.bat` 启动用户端
3. 双击 `admin.bat` 启动管理员端（独立程序）

## 功能说明

### 一、书上基础功能（3.1 ~ 3.6）

- 添加单词
- 修改单词
- 删除单词
- 查询一个单词
- 浏览全部单词
- 随机查看单词

### 二、课设要求功能（3.7，全部完成）

1. **例句管理**：添加/修改单词时可输入例句
2. **发音文件管理**：添加/修改单词时可输入发音音频文件名
3. **发音播放**：查询到单词后点击"发音"按钮播放音频
   > 音频文件放在 `audio` 目录下，支持 `.wav` / `.au` / `.aiff` 格式
4. **模糊查询**：支持前缀查询（开头）、后缀查询（结尾）、包含查询

### 三、自主创新功能

#### 1. 多用户登录系统

- 用户注册、登录、修改密码
- 每个用户拥有独立单词本，数据隔离

#### 2. 独立管理员模块（单独 Java 程序）

- 管理员登录、修改密码
- 删除用户（同时删除该用户所有数据）
- 删除任意单词
- **权限约束**：管理员只能删除，不能修改

#### 3. 艾宾浩斯遗忘曲线复习

- 根据记忆强度动态计算下次复习时间
- 三种反馈：**认识 / 模糊 / 忘记**
- 复习间隔序列：`1天 → 2天 → 4天 → 7天 → 15天 → 30天 → 60天`

#### 4. 随机测验

- 从词库随机抽题，四选一
- 即时判分，记录成绩

#### 5. 学习统计可视化

- 总单词数、已掌握数、待复习数、掌握率
- 最近 7 天学习数据柱状图（新增 / 复习）

#### 6. CSV 导入导出

- 批量导入词库（格式：`单词,释义,例句,发音文件`）
- 导出学习数据

## 数据库说明

- 使用 **Apache Derby 嵌入式数据库**
- 数据库名：`MyEnglishBook`

| 数据表 | 说明 |
|--------|------|
| `word_table` | 单词表（含 sentence / voice / 艾宾浩斯字段） |
| `user_table` | 用户表 |
| `manage_table` | 管理员表 |
| `study_log` | 学习日志表 |

---

## 注意事项

1. 首次运行会自动创建数据库和表，并插入默认账号
2. 发音音频文件请放在 `audio` 目录下，文件名与单词设置的 `voice` 字段一致
3. 同一时间只能有一个程序访问 Derby 数据库（用户端和管理员端不要同时运行）
4. 如需重新初始化数据库，删除 `MyEnglishBook` 文件夹后重新运行即可
